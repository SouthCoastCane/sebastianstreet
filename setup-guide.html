Studio — Setup & Testing Guide

Do the one-time setup first — it unlocks the live embed, the Videos list, and merged chat. Then run through the checklist.

1 One-time setup (unlocks several features)

Set your YouTube channel.
Go to Settings → YouTube channel and paste your Channel ID (it starts with UC…).
Find it in YouTube Studio → Settings → Channel → Advanced settings. This feeds the live player embed, the Videos list, and the merged YouTube chat.
Set your Twitch channel (optional).
Go to Settings → Merged live chat and enter your Twitch username (only if you stream to Twitch too).
Tip: after saving, hard-refresh the page — Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac) — so the latest version loads.

2 Live production (Go Live tab)

Test these while actually broadcasting, camera on.

  • YouTube output — Go Live and confirm YouTube receives the video.
  • Scenes + transitions — press 1/2/3/4 (or the Scene buttons) to switch Camera / Spotlight / Studio / Intro; toggle Cut vs Fade.
  • Hotkeys — M mic, C camera, B banner, 1–4 scenes (ignored while typing).
  • Banner styles — On Air tab: Bar / Rounded / Pill; Show banner; drag it on the preview.
  • Enhance mic — Audio tab: toggle on/off; confirm audio still works after.
  • Multi-camera switch — with 2+ cameras, use the Quick camera switch buttons.
  • Media playback — Media tab: play a video (fills screen) and a music file (over camera); use the level slider; Stop returns to camera.
  • Custom layout — layout Custom: drag a camera tile to move, scroll over it to resize. Grid/Spotlight still work normally.
  • Rundown — add topics/images, set a Length to test the countdown, let it pass 0 for overtime (+m:ss) in red.

3 Recording & clips isolated from live

  • Instant replay — Media tab → Start replay buffer, wait ~40s, then Replay last ~30s (on-air) and Save clip (.webm). Test this hardest.
  • Vertical recording (Shorts) — Media tab → Start, then Stop & save; confirm a 9:16 file centered on you.
  • Record locally — still works as before.

Replay & vertical use extra CPU while on — start them only when needed. They run separately from the live stream, so they can never affect broadcast quality.

4 Merged chat

  • With the channel/Twitch set and live, confirm YouTube (and Twitch) messages appear in the site /live chat and the Studio, each with a badge — Site YT TW.

5 Branding & colors

  • Change Accent / Background / Live in Branding and Save; hard-refresh. Confirm no brown anywhere — panels, sidebar, text/menu, home hero, and the solid LIVE badge all follow your colors. Try a light background too (text should flip dark).

6 Admin & data

  • Videos — after setting your channel, confirm it lists all your uploads (not just a few).
  • Tips → Clear test data (owner) — wipes test tips; totals reset. Stripe is unaffected.
  • Sources tab — confirm the two-part setup note is clear (stream key = video out; Settings = chat in).
Keep this file for handoff. Report anything that misbehaves.
